# rutago-os

Plugins y agentes personales para Claude.

- **[Fuera de ruta](fuera-de-ruta/GUIA.md)** — agente personal de contenido y negocio:
  guiones, videos con IA (Higgsfield), publicación en redes, automatización, monetización
  y cómo crear tus propias skills.

Instalación (Claude Code):

```
/plugin marketplace add zetadiaz92-sys/rutago-os
/plugin install fuera-de-ruta@rutago
```
